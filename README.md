# Анализ рынка вакансий hh.ru для аналитиков данных и системных аналитиков

Учебный исследовательский проект на основе спарсенной базы вакансий с hh.ru.  
Цель — понять, как выглядит рынок труда для аналитиков данных и системных аналитиков:  
зарплаты, регионы, работодатели, типы занятости и востребованные навыки.

## Задачи исследования

1. Определить диапазон зарплат: средние, минимальные и максимальные значения «от» и «до».
2. Выявить регионы и компании с наибольшим числом вакансий.
3. Проанализировать преобладающие типы занятости и графики работы.
4. Изучить распределение грейдов (Junior, Middle, Senior) среди аналитиков.
5. Определить основных работодателей и условия труда.
6. Выявить наиболее востребованные hard и soft skills.

## Данные

Источник — спарсенная база вакансий с **hh.ru**.  
Основная таблица: `public.parcing_table` со следующими ключевыми полями:

| Поле | Описание |
|---|---|
| `name` | Название вакансии |
| `employer` | Компания-работодатель |
| `area` | Регион |
| `salary_from` / `salary_to` | Нижний и верхний порог зарплаты |
| `salary_bin` | Категория «ЗП не указана» |
| `employment` | Тип занятости |
| `schedule` | График работы |
| `experience` | Требуемый опыт (грейд) |
| `key_skills_1..4` | Ключевые (hard) навыки |
| `soft_skills_1..4` | Мягкие навыки |
